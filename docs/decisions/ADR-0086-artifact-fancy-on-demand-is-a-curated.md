# ADR-0086 — Artifact "fancy on demand" is a curated capability vocabulary (motion / marks / diagrams / charts) added the way themes+archetypes were — named primitives in the retroactive shell, under one governed expression dial — and ships inside today's sealed sandbox; a headless render surface (fit-check → vision-repair → optional CDN assets) is the deferred substrate that lifts the ceiling (DESIGNED — 2026-07-15, see docs/plans/artifact-expression-system-v1.md)


**Decision.** Richer artifacts (animation, SVG illustration, "draw objects", diagrams, fancier charts) are added as **more instances of the one pattern the shipped design system already proved** — *never let the model freehand raw CSS/SVG; give it a curated, named, token-derived vocabulary in the retroactive shell and only NAME it in the lean, cache-stable prompt*. Themes and archetypes are two instances of that capability primitive; this adds four more axes. **Layer 1 (ships inside today's `sandbox=""` inline envelope, no infra):** **(A) Motion** — shell `@keyframes` + named classes (`art-rise`/`art-stagger`/`art-draw`/`art-drift`/`art-sheen`), every one wrapped in `@media (prefers-reduced-motion: no-preference)` and forced to final state under `@media print`, autoplay-on-mount (the only motion the sealed, `pointer-events:none`, mount-once iframe permits — and forward-compatible with a future present-mode where mount = build). **(B) Marks** — one curated inline **SVG sprite** in the shell `<defs>` (~16–24 workhorse glyphs), referenced by `<use href="#art-i-…">`, `currentColor`-driven so it themes for free; the model picks an *id*, never draws a path. Plus CSS texture fills. **(C) Diagrams** — a new *category* of archetype (`process`/`timeline`/`comparison`/`quadrant`/`funnel`/`node-graph`) whose SVG connector geometry is **baked into the archetype** so the model fills text, not paths — this is where decks look amateur and freehand fails hardest. **(D) Charts beyond bars** — SVG donut/ring/sparkline parameterized by 1–2 numbers. All of Layer 1 is **retroactive** (edit `tokens.ts`/`shell.ts`, every existing artifact reskins), **cache-cheap** (named not dumped), and **safe by construction** (the shell owns the guards, so the model *cannot* author print- or a11y-breaking motion). Governing all of it is **one explicit expression dial** — `still → lively → showcase` — that scales motion/texture/decor/accent together, defaults restrained, and is inferred from the deck's purpose (financial review = `still`, launch = `showcase`); it generalizes the existing aurora "scale it to the subject" rule across the whole matrix so "on demand" is a *bounded* control, not a license to slop. **Render-target-agnostic — this is one grammar across all artifacts, not just slides.** It is realized three ways by constraint profile: `pages`/`slides` (sandboxed iframe → CSS motion + inline SVG), `pages`/`pdf` (same shell, **static**: marks/diagrams/charts but motion-off for print), and `document`/markdown (**native React in the app DOM, NOT sandboxed** → the `markdown-renderer/` component-registry + `extraRemarkPlugins`/`extraComponents` seam the briefing already uses for `[[kind:id]]` entity chips maps a `:::callout`/` ```chart `/` ```diagram ` vocabulary to design-system components; being native React it can carry *real* motion/interactivity the iframe cannot, and because ReactMarkdown enables no raw HTML the model supplies only data to trusted components — a cleaner injection story than the sandbox). Charts/diagrams are the portable axis (equal value in all three); converging the prose document onto the iframe is rejected (forfeits native-React reading wins). **Theme packs (E)** — promoting `theme.ts` from one house theme to a small set of token-override packs + archetype affinity — is the one axis that needs a contract field + migration + tool param, so it is a separate phase. **Layer 2 (deferred substrate):** a trusted **headless-Chromium render service** (Dimension's `ai-export` shape / a Browserless Railway sidecar) unblocks, in ascending cost: **(3a) deterministic fit-check** (measure the rendered page, feed overflow back → bounded auto-`update`), **(3b) vision critique/repair** (screenshot → vision model + theme/archetype spec + rubric → targeted repair) — Phase 2b of `pristine-artifacts-v1.md` and Alfred's *deliberate edge over Dimension*, which relies on human eyes — and **(3c, gated) asset CDN + relaxed-CSP display** for arbitrary font/icon breadth. The QA loop (3a/3b) renders the **same inline shell server-side at generation time**, so it needs **no CDN and never touches the live sandbox**: generation-time render (QA) is decoupled from view-time render (display).

**Why.** The owner asked to make presentations/documents "fancier on demand" and pointed at Dimension's stack (server-side Playwright with full CDN fonts/Font Awesome) plus its "vision correction". Recon confirmed the shape and the deeper truth: Dimension renders artifacts in a **trusted headless browser with CDN access** and has **no automated visual QA loop**; the original `pristine-artifacts-v1.md` already planned Alfred to *add the floor they lack* (Phase 2b vision-critique) and to run a CDN shell (Phase 3b), both deferred solely on "no headless Chromium ships today." So the owner's two signals are not new ideas — they are the plan's deferred substrate, and they **collapse onto one missing capability** (the render service). The reason to lead with the *vocabulary* rather than the *substrate* is that the design system already discovered the freehand-is-garbage / named-primitive-is-pristine delta (the résumé regression that `templates.ts` fixed), and that delta is the whole thesis: a bigger prompt asking for richer freehand SVG/CSS reproduces exactly the failure the system exists to prevent, breaks the print/reduced-motion invariants, and bloats the per-turn cache. Curated primitives in the retroactive shell get most of the visible "fancy" for zero infra, zero contract change, and zero risk to the invariants — and they are the very vocabulary the later vision-repair loop critiques *against* and repairs *toward* ("use a diagram archetype", not "emit better paths"), so vocabulary-first makes the QA floor cheaper and deterministic-first. The expression dial exists because the hard-won Apple-restraint (the toned-down aurora, "restraint is what keeps a document professional") is precisely what unconstrained "fancy" would undo; making the dial explicit and subject-scaled is what keeps "on demand" from meaning "always a brochure."

**Alternatives.** (a) **Let the model freehand richer CSS/SVG behind a bigger prompt** — rejected: it is the exact failure mode the whole system exists to prevent (unreliable `d=""` paths, off-token type, mid-page voids), it breaks the print + `prefers-reduced-motion` invariants the shell currently guarantees, and it inflates the cache-stable authoring prompt whose size is the recurring token cost. (b) **Go straight to the Dimension CDN-shell + relaxed sandbox as the first move** — rejected: reverses a *deliberate* ADR-0075 security posture (opaque origin, inline-everything, offline, no supply chain), adds a network failure mode, and needs the headless service anyway; Axes A–D deliver the visible richness with none of that, and the sprite + a couple of inlined display faces cover the icon/type-personality that CDN breadth would buy. (c) **Build only the vision-repair loop, skip the vocabulary** — rejected: the loop needs a vocabulary to critique against and repair toward; without it, "repair" degrades to "ask for better freehand", which is unmeasurable and re-opens (a). (d) **JS-driven animation/charts (D3/Framer/anime.js) in the artifact** — rejected: no scripts in the sandbox, and even under a relaxed sandbox it is a supply-chain + perf + print-fidelity cost for what pure CSS keyframes + curated SVG primitives already cover. (e) **Skip the expression dial, make richness always-on** — rejected: undoes the restraint; every deck becomes a brochure. The dial is the governance that makes the capability net-positive. (f) **Bundle the CDN with the QA floor** — rejected: the QA render is generation-time and renders the same inline shell, so it is independent of the CDN; conflating them would gate Alfred's differentiator (the floor) on a security posture reversal it does not need.
